# Working instructions — ASHFORD

Ashford is Mikey's original supernatural comic series. This folder is a writing
project, not software. Nothing in here is part of the PanelForge app.

## Source of truth

| Question | File |
| --- | --- |
| What do I do next? | `README.md` |
| Is this canon? | `bible/series-bible.md` |
| How does a power work? | `bible/world-rules.md` |
| What does a character look like? | `characters/<name>.md` |
| Did that already happen? | `continuity/timeline.md` |
| Did we change something mid-story? | `continuity/continuity-ledger.md` |
| What did we decide, and why? | `decisions/decisions-log.md` |

If two files disagree, `bible/series-bible.md` wins and the disagreement goes in
`continuity/continuity-ledger.md` to be resolved.

## Canon handling — the rule that matters most

Every fact in this project carries one of four labels. Never let a fact move up
a level without Mikey saying so in writing.

- **[CANON]** — Mikey confirmed it. Do not contradict. Do not quietly reword.
- **[DRAFT]** — written material not yet approved. Changeable.
- **[PROPOSAL]** — Claude's suggestion. Has no authority at all.
- **[OPEN]** — a known gap. Do not fill it silently.

A proposal becomes canon only when Mikey says so, and the promotion is recorded
in `decisions/decisions-log.md` with the date.

If a new idea contradicts [CANON], stop. Say what contradicts what, recommend a
resolution, and wait. Do not rewrite established facts to fit a better idea.

## Originality

The Slayer/Watcher framework resembles existing fiction. Flag derivative
elements plainly and offer alternatives, but never rename or replace confirmed
terminology without asking. Never make claims about legal clearance — that is
not something Claude can assess.

## Images

Never state that a reference image has been seen unless it is actually present
in this folder and has actually been opened. `characters/reference-status.md`
tracks which references exist. As of the last check: none do.

## Working style

- Small, finishable units of work. One page or one scene at a time.
- Two focused questions maximum, and only when the answer changes the next deliverable.
- Keep story detail in the story documents, not in this file.
- Do not install anything, publish anything, or send anything without Mikey's go-ahead.
