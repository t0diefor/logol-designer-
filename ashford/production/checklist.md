# Production checklist

A per-page workflow built for one person working alone. The point is to make
a page a **finishable object**, so that progress is visible and the project
survives the months where motivation does not.

---

## Before any page
- [ ] The scene it belongs to is outlined
- [ ] Every character on the page has an approved design
- [ ] `continuity/continuity-ledger.md` checked for weather, time of day,
      costume and injuries
- [ ] No [OPEN] question blocks the page — if one does, script around it or
      pick a different page

## Per page
1. [ ] **Script** — purpose, panels, art directions, dialogue separated
2. [ ] **Thumbnail** — the whole page at postcard size. If it does not read at
       that size it will not read at print size
3. [ ] **Word count** — can a letterer fit this? Target under 150 words a page,
       under 25 in an action or silent page
4. [ ] **Pencils**
5. [ ] **Inks**
6. [ ] **Flats / colour**
7. [ ] **Letters**
8. [ ] **Continuity pass** — compare against the ledger, then update it
9. [ ] **Log it** in `continuity/timeline.md`

## Per issue
- [ ] Read all pages in order, in one sitting, on a phone-sized screen
- [ ] Does every scene change the situation?
- [ ] Is anything explained twice?
- [ ] Does any character solve a problem only because they have powers?
- [ ] Update the bible with anything the issue made true
- [ ] Move any resolved items out of `decisions/open-questions.md`

---

## Rules of thumb for not burning out
- **One page at a time.** Never schedule an issue; schedule a page.
- **Script further ahead than you draw.** Writing is the cheap part, and a page
  drawn from a thin script gets redrawn.
- **Never redraw a finished page** because the style has improved. Style drift
  across a first comic is normal and readers forgive it. Redrawing is where
  projects die.
- **Pick cheap pages when tired.** Four panels in one location beats a splash
  you will abandon.
- **Stop at a page boundary**, never mid-page.
