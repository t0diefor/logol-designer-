Export note: SVG text uses fallback fonts. For consistent print results, open the SVG in a design program and convert text to outlines before sending it to a printer. Logo Lab cannot do this itself — no browser exposes glyph outlines, and doing it properly requires parsing the font file.
About PNG: the SVG is reproducible anywhere. A PNG is not — it bakes in whatever font this computer resolved from the stack. Treat the SVG as the master file.
